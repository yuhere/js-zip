@yuhere/js-zip

Create and read .zip files in the browser

Create a zip file

    View source — create zip 
    import { BlobWriter, TextReader, ZipWriter } from "@yuhere/js-zip";

const writer = new ZipWriter(new BlobWriter("application/zip"));
await writer.add("hello.txt", new TextReader("Hello world!"));
const blob = await writer.close();
// → download blob as demo.zip
